# fixtures/

Reserved for public, reproducible evidence fixtures used by live Studionet
verification (spec section 31: "A public GitHub fixture is acceptable for
reproducible controlled condition changes if clearly labeled as a fixture,
pushed before live execution, genuinely retrieved through GenLayer, and
not misrepresented as independent real-world truth.").

Empty in this session because no live deployment/verification was
performed yet (see `docs/DEPLOYMENT.md`). Direct Mode tests use inline
`vm.mock_web`/`vm.mock_llm` fixtures instead (see `tests/direct/_helpers.py`).
